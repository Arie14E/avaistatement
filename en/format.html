Open format · version 0.1

One language for AI transparency.

Origin Report is a compact declaration signed by the makers. It describes eleven production stages using three fixed values, making it readable for people and useful in digital systems.

Three values

Simple to choose, precise to explain.

Fixed values make reports comparable. An optional note and list of tools leave room for the nuance of each production.

No generative AI

No material in this stage was created or substantively altered with generative AI.

AI-assisted

AI supported the process or altered elements, but did not independently determine the complete final result.

AI-generated

Material in this stage was largely or fully produced by a generative model.

Full chain

Eleven stages in four blocks.

The structure follows film and video production practice, making it clear exactly where AI entered the chain.

Open file

A small JSON file travels with the film.

The declaration can be downloaded as .origin.json and published alongside the film. AI-assisted and AI-generated entries can also reference existing IPTC Digital Source Type terminology.

{
  "format": "origin-report",
  "version": "0.1",
  "title": "The Last Frame",
  "stages": {
    "script": { "value": "none" },
    "vfx": { "value": "assisted",
      "tools": ["Example tool"] }
  },
  "signed": { "name": "...", "date": "..." }
}
