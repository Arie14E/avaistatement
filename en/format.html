Different jobs

Each layer has one clear purpose.

The terminology sounds technical, but the division is straightforward.

ORIGIN REPORT ID

Points to the report

A stable local number such as OR-….

JSON

Carries the declaration

The complete, machine-readable production report.

IPTC

Names the source type

A controlled term such as compositeSynthetic.

C2PA

Binds data to an asset

A signed manifest accompanying the final video, image or audio.

Short answer to “what is the code useful for?” The Origin Report ID recognises one report. JSON prevents repeated data entry and can later be read by festivals, broadcasters, archives or a registry. IPTC terms make source information interoperable. A later C2PA step can bind selected information verifiably to the media asset.
