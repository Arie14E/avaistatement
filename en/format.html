One language for AI transparency.

Origin Report is a compact declaration signed by the makers. It describes eleven production stages with four clear answers and names the crafts involved.

Four answers

Simple to choose, precise to explain.

Fixed answers make reports comparable. A note per stage leaves room to name tools and describe concrete changes.

Not used

No material in this stage was created or substantively altered with generative AI.

As a tool

AI supported the process while the maker retained the defining creative choices and final result.

In final material

Generated or substantially altered content is a recognisable part of the finished work.

Not applicable

This stage did not exist or played no role in this production.

Full chain

Eleven stages, every craft.

The main stages keep the report compact. Each explicitly names its relevant departments. Delivery and campaign can be switched off entirely when they are outside the declaration’s scope.

Open file

A small JSON file travels with the film.

The declaration can be downloaded as .origin.json and published alongside the film. Its machine-readable structure avoids duplicate work and uses IPTC digital-source terminology where appropriate.

{
  "format": "origin-report",
  "version": "0.2",
  "scope": { "deliveryCampaignIncluded": true },
  "stages": {
    "camera": {
      "value": "none",
      "departments": ["camera", "lighting", "grip", "production sound"]
    }
  }
}
