Example

A recognisable key, not a secret code.

AVAI-7K3M-9Q2D-H6WT-8P4N-F identifies the report. Its characters reveal nothing about title, maker or AI use. The final character helps detect transcription errors.

"identifier": {
  "scheme": "audiovisual-ai-statement",

  "status": "local-unregistered"
}
What it does and does not do

Identification is not yet registration.

The number does

  • Keep the same report recognisable after minor changes.
  • Appear in JSON, print/PDF and credit text.
  • Distinguish local reports on one device.
  • Remain suitable for a future registry.

The number does not

  • Prove that the declaration is true.
  • Resolve publicly yet.
  • Replace ISAN or identify the film itself.
  • Replace a signature or Content Credential.
Local storage

The device keeps the connection.

The site stores the number and draft in this browser. “Download draft” creates a separate backup. Clearing browser data may remove the local copy; a downloaded file remains available.

01

Create

The browser generates a random number from a very large set of possibilities.

02

Store

All changes remain under the same ID on this device.

03

Publish later

A future registry can register and resolve the same ID.

For the credits: while no public registry exists, use Audiovisueel AI Statement ID: AVAI-… · full report available from the producer. This avoids suggesting that the number is already verifiable online.
