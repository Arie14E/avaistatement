# Origin Report

A bilingual, static website for transparent declarations about generative AI use in film and video production.

## Run locally

Serve this directory with any static web server and open `/nl/` or `/en/`.

## Publish with GitHub Pages

1. Push the contents of this directory to a GitHub repository.
2. In **Settings → Pages**, choose **Deploy from a branch**.
3. Select the `main` branch and the root directory.

The site has no build step, framework, account system, analytics or form submission. Declaration data is processed only in the visitor's browser. GitHub Pages may still process visitor IP addresses as part of its hosting and security operations.
