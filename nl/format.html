Kort antwoord op “wat heb ik aan de code?” Het Origin Report ID helpt één rapport herkennen. Het JSON-bestand voorkomt opnieuw invoeren en kan later door festivals, omroepen, archieven of een register worden ingelezen. De IPTC-termen maken broninformatie uitwisselbaar. Een latere C2PA-stap kan geselecteerde informatie controleerbaar aan het mediabestand koppelen.
