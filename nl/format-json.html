JSON-format
uitgelegd.

De “gegenereerde code” is geen programma. Het is een gestructureerd gegevensbestand: dezelfde verklaring, maar zo opgeschreven dat mensen én computers haar kunnen lezen.

Origin Report IDIPTCC2PA / Content CredentialsJSON-format

JSON is de verpakking; Origin Report bepaalt de inhoud.

JSON gebruikt namen, waarden, lijsten en geneste blokken. Daardoor blijft “VFX: AI als hulpmiddel” exact hetzelfde gegeven wanneer het later naar een festivalformulier, spreadsheet, archief, website of database wordt overgezet. Een tekst-PDF is prettig om te lezen; JSON is beter om betrouwbaar te hergebruiken.

Concrete toepassingen

Wat kun je naast het rapport met de code?

01

Festivalformulier invullen

Een festival kan later dezelfde twaalf fases importeren en alleen de relevante antwoorden tonen.

02

Omroep of opdrachtgever

Een systeem kan automatisch een korte AI-samenvatting genereren zonder het hele rapport over te typen.

03

Archief en overdracht

Het bestand kan naast masters, contracten en cue sheets worden bewaard als duurzame productie-informatie.

04

Openbaar register

Een toekomstig register kan het JSON-bestand inlezen, controleren op formaat en onder het bestaande ID publiceren.

05

Credittekst maken

De tellingen en het Origin Report ID kunnen automatisch worden omgezet naar een consistente aftitelingstekst.

06

C2PA voorbereiden

IPTC-termen en een samenvatting kunnen als kandidaten worden doorgegeven aan een echte C2PA-workflow.

Klein voorbeeld

Lees het als een formulier met labels.

value is het gekozen antwoord. departmentsAffected noemt de betrokken vakgebieden. extent bewaart de benadering van hoeveelheid, beeld en geluid. iptc bevat de gestandaardiseerde bronterm.

"vfx": {
  "value": "generated",
  "departmentsAffected": ["VFX", "compositing"],
  "extent": {
    "approximate": true,
    "percentage": 5,
    "imageCoverage": "partial",
    "soundCoverage": "none"
  }
}

Grenzen

Een bestand is nuttig, maar geen bewijs op zichzelf.

Kan iemand JSON aanpassen?

Ja. JSON is gewone tekst. De ondertekening is momenteel een zelfverklaring. Een register, digitale hash of C2PA-koppeling kan later beter zichtbaar maken of een bestand is veranderd.

Is het Origin Report ID hetzelfde als JSON?

Nee. Het ID is het nummer op de envelop; JSON is de inhoud van de envelop.

Kan ik het bestand openen?

Ja, met iedere teksteditor of moderne browser. Voor dagelijks lezen blijft een print/PDF vaak prettiger.

Waarom geen eigen geheim formaat?

Een open tekstformaat voorkomt afhankelijkheid van één leverancier en maakt latere migratie eenvoudiger.

Praktisch bewaren: plaats het definitieve .origin.json-bestand naast de master en bewaar ook een leesbare PDF. Het JSON-bestand is voor uitwisseling en automatisering; de PDF is voor mensen.
